# luci-app-guestwifi — Гостевой Wi-Fi с расписанием

Приложение LuCI для OpenWrt 25.x (mediatek/filogic, проверено на Cudy TR3000 v1):
гостевая Wi-Fi сеть, которая включается/выключается **по расписанию на неделю**
и **автоматически меняет имя (SSID) при смене даты**.

## Возможности

- Выделенная гостевая сеть: bridge `br-guest`, подсеть по умолчанию `192.168.9.1/24`,
  DHCP на гостях, firewall-зона `guest` (input REJECT + разрешены только DHCP/DNS,
  forwarding только в `wan`), изоляция клиентов (`isolate`) на обоих диапазонах.
- Ограничение доступа к роутеру (галочка): гостевые клиенты не имеют доступа
  к самому роутеру (LuCI/SSH и пр.) — разрешены только DHCP и DNS; управляется
  политикой `input` зоны `guest` (REJECT/ACCEPT).
- Ограничение полосы для гостей (галочка + значения Мбит/с): скачивание
  (к гостям, HTB на выходных интерфейсах гостевых AP) и отдача (от гостей,
  police на ingress). Лимит суммарный на всех гостей, применяется только пока
  активна сеть. Требует пакетов `tc` (tc-full), `kmod-sched-core`,
  `kmod-sched-act-police` — ставятся автоматически uci-defaults, если есть
  доступ в интернет; без `tc` шейдер просто не применяется.
- Персональный лимит «На каждого гостя» (Мбит/с): каждому DHCP-клиенту гостевой
  подсети создаётся свой HTB-класс (скачивание) и свой police (отдача), чтобы
  один гость не мог занять весь канал. Список клиентов берётся из
  `/tmp/dhcp.leases`; новый гость появляется под лимитом в течение минуты
  (cron-минутная пересборка). Клиент, получивший статический IP в обход DHCP,
  попадает в общий (не персональный) класс.
- Режимы работы: **always** (всегда), **schedule** (по расписанию), **off**.
  Расписание: галочка на каждый день недели + интервал ЧЧ:ММ — ЧЧ:ММ (может пересекать полночь).
- Изменения вносятся обычным LuCI-потоком: галочка наверху активирует/деактивирует
  сеть, значения попадают в staged uci и применяются штатной кнопкой
  **Save & Apply** (внизу страницы). Отдельных кнопок в приложении нет.
- Авто-смена SSID (вкл/выкл галочкой): имя сети = `<указанное>` + `_` +
  `<текущая дата>` (напр. `Guest_02.11.2026`). Бэкенд переименовывает сеть
  автоматически, как только меняется дата (cron запускается каждую минуту).
- Живой статус со обновлением каждые 30 с.

## Файлы

| Путь | Назначение |
|------|------------|
| `root/usr/bin/guestwifi` | Бэкенд: `check` (cron каждую минуту), `status`, `on`, `off` |
| `root/etc/config/guestwifi` | Конфиг UCI |
| `root/etc/init.d/guestwifi` | Автозапуск при загрузке |
| `root/etc/uci-defaults/40_luci-guestwifi` | Создание сети/dhcp/firewall/guest-AP-ов и cron |
| `root/www/luci-static/resources/view/guestwifi/guestwifi.js` | Интерфейс LuCI |
| `root/usr/share/luci/menu.d/…json`, `root/usr/share/rpcd/acl.d/…json` | Меню и права доступа |

## Формат расписаний

`<дни>|<HH:MM>|<HH:MM>`, дни: `1,2,3`, `1-5` (1=Пн … 7=Вс).

```
list schedule '1,2,3,4,5|08:00|23:30'   # сеть работает Пн–Пт с 8:00 до 23:30
list schedule '6,7|10:00|23:59'
option ssid_schedule '1'                 # авто-смена SSID вкл
option ssid_base 'Guest'                 # → Guest_02.11.2026
option fw_block_router '1'               # 1 = запрет доступа к роутеру (кроме DHCP/DNS)
option limit_enabled '0'                 # ограничение полосы вкл/выкл
option limit_down '0'                    # кбит/с к гостям (0 = без лимита)
option limit_up '0'                      # кбит/с от гостей
option limit_per '0'                     # кбит/с на каждого клиента (0 = общий лимит)
```

## Быстрая установка (dev, на работающий роутер)

Из рабочей папки проекта:

```
python dev/gw-deploy.py
```

Скрипт копирует файлы на `root@192.168.1.1`, запускает uci-defaults, рестартует
rpcd/uhttpd, проверяет статус. Повторный запуск безопасен (идемпотентен).

## Установка из релиза (готовые пакеты)

Скачайте пакет под вашу версию OpenWrt со страницы
[Releases](https://github.com/jeysson89/luci-app-guestwifi/releases):

- **OpenWrt 24.10** (`ipk`, пакетный менеджер opkg), файл: `luci-app-guestwifi_1.0.0-r1_all.ipk`;
- **OpenWrt 25.x** (`apk`, пакетный менеджер apk-tools), файл вида `luci-app-guestwifi-1.0.0-r1.apk`.

На роутере (пример, 24.10):

```
opkg update
opkg install ./luci-app-guestwifi_1.0.0-r1_all.ipk
```

Для 25.x (пакет не подписан — устанавливается с разрешением неподписанных):

```
apk add --allow-untrusted ./luci-app-guestwifi-1.0.0-r1.apk
```

После установки перезагрузите роутер или выполните
`/etc/uci-defaults/40_luci-guestwifi && /etc/init.d/guestwifi enable` —
создадутся сеть `guest`, firewall-зона, AP-ы и cron; страница появится в
LuCI: **Сеть → Гостевая Wi-Fi**.

Для сборки пакета своими руками — OpenWrt buildroot (SDK соответствующей
версии, целевой mediatek/filogic), стандартно
`make package/luci-app-guestwifi/compile V=s`; готовый workflow сборки лежит
в `.github/workflows/release.yml`.

## Проверка

```
/usr/bin/guestwifi status        # JSON: {"state":…,"expected":…,<iface>:{ssid,up}}
logread | grep guestwifi         # журнал переключений
```
